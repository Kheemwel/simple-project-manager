# Simple Project Manager

This web app offers basic and simple project management features. You can create projects, add task and manage its status. The data is local using Dexie.js, meaning your data is save locally in your browser. You don't have to create an account or anything. You can use the app right away 🙂. About your progress... Well... use the app at your own risk. 😁

Anyways, this project is my another attempt of making an app that I'm the one writing the code. But I failed again, and I think I have to surrender. I guess I'll have to change my style of making apps or writing code. I think being the director or visionary is the best I can do while letting the AI do the menial and tedious tasks.

### Tech Stack:

- Svelte 5
- Sveltekit
- shadcn-svelte
- Dexie.js
- Tailwind CSS 4
